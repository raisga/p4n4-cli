**p4n4 0.2.1** stops every project on the host with one command, runs stacks under emulated hardware, and makes `up` and `secret rotate` safer.

```bash
pipx install p4n4==0.2.1    # or: pip install p4n4==0.2.1 (Python 3.11+)
```

> **Trusted networks only.** p4n4 0.2.x is meant for development and trusted local networks. Don't expose its service ports to the internet or to networks you don't control.

## Highlights

- **`p4n4 down --all`:** stops every p4n4 project on the host, from any directory. It lists each project with its folder and containers and asks first. `--volumes` also deletes their data.
- **`p4n4 up --emu <profile>`:** runs the stacks under [p4n4-emu](https://github.com/raisga/p4n4-emu) with a hardware profile (`rpi4`, `rpi5`, `nuc`, `mcu-class`). `p4n4 down` stops them through `p4n4-emu down`.
- **No more half-started projects:** `p4n4 up` checks every stack before starting any. If another p4n4 project holds the `p4n4-*` container names, it says which one and how to stop it, instead of failing midway with "container name is already in use".
- **Secret rotation won't lock you out:** `p4n4 secret rotate` no longer rotates `INFLUXDB_PASSWORD`, `INFLUXDB_TOKEN`, `GRAFANA_PASSWORD` or the n8n keys. Their services keep the value from first setup, so a new value in `.env` alone locked clients out of InfluxDB and Grafana and stopped n8n from starting. The [Security guide](https://github.com/raisga/p4n4-docs/blob/main/guides/security.md#secret-rotation) explains how to change them inside the services.
- **`p4n4-net` handled for every layout:** `up` creates the shared network when it's missing, so AI-only and edge-only projects start, as does `p4n4 up ai` while IoT is down. A `p4n4-net` made with `docker network create` is recreated with Compose's label, so iot no longer fails with "incorrect label".

## Fixes

- `p4n4 status` lists stopped and crashed services, and reports Docker or Compose errors instead of "No services found".
- Ctrl+C at a `p4n4 init` prompt aborts instead of taking the default and carrying on.
- `p4n4 init` checks that a typed n8n encryption key has 32 characters, and writes `TZ` to the AI layer's `.env` so n8n uses the project's timezone.

## Compatibility

- Requires **p4n4-lib 0.2.1** (installed with it).
- `--emu` needs `p4n4-emu` on `PATH` (`uv tool install git+https://github.com/raisga/p4n4-emu`).
