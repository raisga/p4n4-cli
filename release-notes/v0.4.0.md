**p4n4 0.4.0** merges the edge layer into the ai layer, where the edge inference runner becomes the `ei-runner` profile, adds the optional extras layer, and moves existing projects over with `p4n4 migrate edge`.

```bash
pipx install p4n4==0.4.0    # or: pip install p4n4==0.4.0 (Python 3.11+)
```

> **Trusted networks only.** p4n4 0.4.x is meant for development and trusted local networks. Don't expose its service ports to the internet or to networks you don't control.

## Highlights

- **Runner in the ai layer:** `p4n4 init --ei-runner/--no-ei-runner` runs the edge inference runner as the ai layer's `ei-runner` profile. It's on with `--layer all`, which ran it as the edge layer before, and the wizard asks.
- **`p4n4 migrate edge [--source-ai PATH] [--yes]`:** moves a project's edge layer into the ai layer (the runner's service, `runner/`, models and `.env` values, with `ei-runner` added to `COMPOSE_PROFILES`), scaffolding a new ai layer when the project has none. When the edge layer runs other services, it renames it to `extras` with the same volumes. What it replaces stays in `edge.pre-migrate/`. It refuses while the edge layer runs.
- **Extras layer:** `--layer extras` and `--source-extras` add p4n4-extras, optional services outside the core. It starts with nothing enabled and is never part of `--layer all`.
- **Project `.gitignore`:** `p4n4 init` writes one at the project root, covering every layer's `.env`, Mosquitto's `passwd`, ACL and certificates, Node-RED's credentials, model files, p4n4-api's data and `edge.pre-migrate/`.
- **`p4n4 up`** skips a stack with no service enabled instead of failing with Compose's "no service selected", with or without `--emu`.

## Compatibility

- Requires **p4n4-lib 0.4.0** (installed with it).
- Projects scaffolded by 0.4.0 pin **p4n4-dashboard 1.3.0** (`--layer dashboard`), which pairs with **p4n4-api 0.3.0**.

## Upgrading from 0.3.x

- **Breaking:** `--layer edge` and `--source-edge` are gone. Use `--layer ai --ei-runner` (`--layer edge` now says so).
- Projects with an `edge` layer keep working, and every command reminds you to move them. Stop the edge layer, then run `p4n4 migrate edge`. Check the project runs, then delete `edge.pre-migrate/`.
- Projects scaffolded before 0.4.0 have no `.gitignore`, so their `.env` files (generated secrets) could have been committed. If the project is a git repository, check `git ls-files '*.env'` and treat any secret that was pushed as leaked.
